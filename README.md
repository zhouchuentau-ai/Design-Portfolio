# Zhou Chuentau Portfolio

29 页个人作品集静态网站，包含作品展示、详情长图、动画及视频。

## 本地预览

运行 `python -m http.server 4173`，在浏览器打开 http://localhost:4173 。

## 部署到 Vercel

将本仓库导入 Vercel。Framework Preset 选择 Other；无需安装和构建命令；Output Directory 使用仓库根目录 `.`。

## 文件

- index.html：页面入口
- style.css：页面排版和动效
- app.js：翻页、长图滚动与视频播放
- media.js：素材索引
- assets/：网站图片、字体及视频素材
